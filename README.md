# لعبة الغاز الذكاء (اختيار من متعدد)

لعبة أسئلة ترفيهية بنمط **اختيار من متعدد** مع **مؤقت** و**تسجيل للتقدم** (باستخدام `localStorage`). الأسئلة كلها داخل ملف `script.js`، والصوتيات داخل `correct.mp3` و `wrong.mp3`.

> ملاحظة: الواجهة عربية باتجاه RTL.

---

## المعاينة / التشغيل

ما تحتاجه هو فتح الملف مباشرة في المتصفح:

1. افتح `index.html`.
2. ابدأ بالإجابة.

✅ لا يوجد أي اعتماد على مكتبات خارجية أو خطوات بناء.

---

## طريقة اللعب

- لديك **15 ثانية** للإجابة عن كل سؤال.
- الإجابة الصحيحة:
  - تحصل على **+10 نقاط**.
  - يتم تشغيل صوت `correct.mp3`.
- الإجابة الخاطئة أو انتهاء الوقت:
  - يتم تشغيل صوت `wrong.mp3`.
- زر **التالي ➡️** يظهر بعد اختيار الإجابة.
- يتم حفظ أعلى مستوى وصلته سابقًا عبر:
  - `maxLevel` في `localStorage`.

---

## هيكل المشروع

- `index.html` : صفحة اللعبة وتهيئة العناصر (السؤال/الخيارات/النتيجة).
- `style.css` : تنسيق واجهة اللعبة وتلوين الإجابات الصحيحة/الخاطئة.
- `script.js` : منطق اللعبة، عرض الأسئلة، إدارة المؤقت، حساب النقاط.
- `utils/timer.js` : ملف مؤقت (غير مستخدم حاليًا في `index.html` إلا إن كان مقصودًا لاحقًا؛ يتم تشغيل المؤقت من `script.js`).
- `correct.mp3` / `wrong.mp3` : مؤثرات صوتية.
- `puzzle.png` : أيقونة التطبيق.

---

## المميزات

- أسئلة متعددة (مصفوفة `puzzles`) داخل `script.js`.
- مؤقت لكل سؤال مع معالجة انتهاء الوقت.
- تمييز بصري للإجابة الصحيحة والخاطئة.
- حفظ التقدم (أعلى مستوى) باستخدام `localStorage`.
- إعادة ضبط التقدم عبر زر **إعادة تعيين التقدم**.

---

## تعديل الأسئلة (اختياري)

كل سؤال موجود داخل مصفوفة `puzzles` في `script.js` بالشكل التالي:

```js
{
  title: "المستوى 1",
  question: "نص السؤال...",
  options: ["الخيار 1", "الخيار 2", "الخيار 3", "الخيار 4"],
  answer: "نص الخيار الصحيح بالضبط"
}
```

> شرط مهم: قيمة `answer` يجب أن تطابق نص أحد الخيارات الموجودة داخل `options`.
